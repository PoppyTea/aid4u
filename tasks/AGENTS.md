# Tasks Module

## Purpose
Execution environment for AI_Devs 4 course tasks.

## Ownership
- Each folder (`sXXeYY`) acts as a domain for a specific task.

## Local Contracts
- Every task solution MUST contain `solution.py` and `test_solution.py`.
- Task execution via `uv run run.py solve sXXeYY`.

## Work Guidance
- Follow TDD: create test file first.
- Always use `writing-plans` skill before writing code.

## Verification
- Pass all local tests in `test_solution.py`.

## Child DOX Index
- None.
