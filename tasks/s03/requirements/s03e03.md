# s03e03 — reactor (przed podejściem)

**Zadanie:** poprowadź robota przez planszę 7×5, omijając ruchome bloki reaktora
(cyklicznie góra/dół, poruszają się TYLKO gdy wydajesz polecenie). Komendy: `start`,
`reset`, `left`, `right`, `wait`.

**Najłatwiejsze zadanie sezonu wg społeczności** — traktuj jako rozgrzewkę, nie jako
poligon do przesadnej architektury.

## Zanim zaczniesz

- [ ] Rozważ zrobienie tego BEZ LLM w ogóle — API zwraca pełny stan planszy, więc to
  klasyczny problem CS (symulacja + planowanie), nie zadanie językowe. Kilku
  uczestników zrobiło to czystym BFS w 8-12 ruchach.
- [ ] Jeśli jednak z modelem: nie wysyłaj surowego stanu API — LLM-y są słabe w
  rozumowaniu przestrzennym 2D i "wchodzą" w bloki. Pre-digest planszy (tabela
  markdown / jawne "ruch w lewo/prawo teraz niebezpieczny") działa lepiej.
- [ ] **Programistyczny override jest jawnie błogosławiony przez staff:** jeśli model
  mówi `right` a pole po prawej zajęte — wymuś `wait` w kodzie, nie ufaj ślepo
  decyzji modelu. To hybryda, nie oszustwo.
- [ ] Feeduj modelowi tylko LOKALNE sąsiedztwo planszy, nie całość — oszczędza tokeny
  i redukuje szum.
