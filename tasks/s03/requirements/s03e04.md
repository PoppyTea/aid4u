# s03e04 — negotiations (przed podejściem)

**Zadanie odwraca role:** TY budujesz i publicznie hostujesz 1-2 narzędzia HTTP;
CUDZY agent (po stronie Centrali) je wywołuje, żeby znaleźć miasta oferujące
wszystkie potrzebne przedmioty. Odpowiedź narzędzia: 4-500 bajtów. Agent ma 10 kroków.
Weryfikacja asynchroniczna (`action: "check"`, min. 30-60s po zgłoszeniu).

**Łatwe i tanie wg społeczności** — nie przeinżynierować.

## Zanim zaczniesz

- [ ] Publiczny endpoint gotowy: `core/server/factory.py` (`ServerFactory.create()`),
  wzorzec z `s01e03_proxy/server.py` (żywy publiczny endpoint — sprawdzony bojowo),
  `deploy/ngrok_tunnel.sh` (ngrok 3.39.10 zainstalowany, port domyślny 8003).
- [ ] Pobierz dane wejściowe przez `hub.get_public("dane/s03e04_csv/")`.
- [ ] 🚨 **Hub wymaga DOKŁADNIE 2 narzędzi w zgłoszeniu** (`Field "tools" must
  contain exactly 2 elements`). Jeśli projekt potrzebuje jednego — zarejestruj to
  samo narzędzie dwa razy.
- [ ] Przećwicz `https://hub.ag3nts.org/debug` PRZED pierwszym zgłoszeniem — pokazuje
  realny ruch z cudzym agentem, najbardziej niedoceniane narzędzie tego epizodu.

## Gotchas potwierdzone przez społeczność

- `-500 "No results yet..."` = normalne, po prostu ponów `check`, nie błąd.
- Zły host → `-166 task not found (AI_Devs 3)`.
- **Pułapka w danych:** zduplikowane kody przedmiotów (dwa różne przedmioty dzielą
  ten sam kod) — jeśli kluczujesz słownik po kodzie, jeden po cichu nadpisze drugi.
- Semantyka celu: miasta oferujące WSZYSTKIE potrzebne przedmioty NARAZ, nie
  którykolwiek.
- Zapytania cudzego agenta są krótkie i precyzyjne — naiwne dopasowanie top-1 może
  wyglądać na wystarczające tu, ale nie jest to wzorzec produkcyjny.

## Architektura

Deterministyczne podejście (CSV → mapa w pamięci, bez LLM) w pełni wystarcza —
potwierdzone jako działające. SQLite jako narzędzie `query` chwalone przez staff.
LLM potrzebny tylko do wyciągnięcia nazwy przedmiotu z zapytania w języku
naturalnym, jeśli w ogóle.

⚠️ Uwaga kosztowa z komentarzy: to nie koszt LLM był problemem (<$0.01), tylko
asystenci kodujący — jedna osoba straciła ~$5 gdy Claude Code próbował "naprawić"
obcięte duże pliki danych czytając je w całości do kontekstu. Rozważ odmowę
wczytania payloadu >40 kB bez potwierdzenia.

Pełny kontekst: `source/tool-inventory.md` (sekcja 2.1), `source/community-intel.md`
(sekcja s03e04).
