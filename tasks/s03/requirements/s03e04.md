## Protokół (z treści zadania, zweryfikowany)

Rejestracja — `POST /verify`:
```json
{"apikey":"…","task":"negotiations","answer":{"tools":[
  {"URL":"https://…/search","description":"…"},
  {"URL":"https://…/cities","description":"…"}]}}
```
- Klucz to **`URL` wielkimi literami** + `description`. **Pola `name` NIE MA.**
- 🚨 **Hub wymaga DOKŁADNIE 2 elementów** (`Field "tools" must contain exactly 2
  elements`), mimo że treść zadania mówi „możesz ogarnąć wszystko jednym".

Agent → narzędzie: `{"params": "<język naturalny>"}` → narzędzie: `{"output": "…"}`

Odbiór flagi — **`action` wewnątrz `answer`**:
```json
{"apikey":"…","task":"negotiations","answer":{"action":"check"}}
```

Limity: odpowiedź **4–500 bajtów**, agent ma **10 kroków**, szuka **3 przedmiotów**,
**brak odpowiedzi = agent przerywa pracę**.

## Gotchas
- `-500 "No results yet…"` = normalne, ponów. Zły host → `-166 task not found`
  (w tej edycji `hub.ag3nts.org`).
- **Pułapka zduplikowanych kodów już NIE ISTNIEJE** — dane załatano
  (`06OTEA`/`06OTEB`), wszystkie 2137 kodów i nazw są unikalne. Komentarze kursu
  opisują stan sprzed łatki.
- **Łatka zostawiła sierotę:** `Akumulator kwasowy 12V 200Ah` (`06OTEB`) nie ma
  ANI JEDNEGO miasta. Pusty wynik jest dla niej poprawny — ale musi schodzić na
  koniec rankingu, inaczej prowadzi agenta w ślepy zaułek.
- **306 z 2137 kodów nie ma cyfry** — kształtu `[A-Z0-9]{6}` nie odróżnisz od
  polskiego słowa („PROSZE"). Waliduj kandydatów wobec katalogu.
- Semantyka celu: miasta oferujące WSZYSTKIE przedmioty NARAZ, nie którykolwiek.
- W katalogu nie ma kabli ani kontrolerów ładowania — „kabel 10m" z treści
  zadania to ilustracja, nie pozycja z tego zbioru.

## Architektura (co faktycznie zadziałało)
Deterministycznie, **zero LLM**. Punktowanie pokrycia rdzeni tokenów NAZWY, z
parametrami technicznymi jako bonusem rankingowym — to obsługuje polską odmianę
(„szukam turbiny wiatrowej" wobec „Turbina wiatrowa 400W 48V"), na której pada
dopasowanie po podciągu.

⚠️ Uwaga kosztowa: koszt LLM to nie problem (<$0.01), tylko asystenci kodujący —
jedna osoba straciła ~$5, gdy Claude Code próbował „naprawić" obcięte duże pliki
danych, czytając je w całości do kontekstu. `items.csv` (94 kB) i
`connections.csv` (73 kB) czytać programowo, nigdy w całości do kontekstu.
