# s03e05 — savethem (przed podejściem)

**Zadanie:** zaplanuj trasę do miasta Skolwin. Brak statycznej listy narzędzi — tylko
`/api/toolsearch` (zwraca 3 najlepiej dopasowane wyniki, nigdy wszystkie). Mapa 10×10,
budżet 10 jedzenia + 10 paliwa, wybór pojazdu wpływa na zużycie obu zasobów.

**Trudne wg społeczności, razem z s03e02** — dwa odrębne, dobrze udokumentowane tryby
porażki poniżej. Prawie każdy trafia w co najmniej jeden.

## Zanim zaczniesz

- [ ] Zaakceptuj, że `run_agent_loop(tools=[...])` bierze dziś TYLKO statyczną listę
  — to zadanie wymaga narzędzi odkrywanych w runtime. Sprawdź `season.md` (dług
  "dynamiczne odkrywanie narzędzi") czy to już zaadresowane, zanim zaczniesz
  implementację.
- [ ] Zaplanuj DWUFAZOWĄ architekturę (potwierdzona niezależnie przez kilku
  uczestników jako wygrywająca): (1) tani/słaby explorer-agent odkrywa narzędzia i
  zrzuca WSZYSTKO (mapa, pojazdy, "books") do pliku/pamięci; (2) osobny planner
  dostaje tylko strawiony stan i albo deterministyczny BFS z symulacją
  paliwa+jedzenia, albo silny model zmuszony do jawnego wypisania trasy krok po
  kroku `(x, y, fuel, food, action)` przed zgłoszeniem.

## Tryb porażki #1: agenci prawie nigdy nie odkrywają `/api/books`

Tam siedzi legenda mapy (symbole) i reguły ruchu. Agenci zapętlają się pytając
`/api/maps` o legendę której tam nie ma, potem HALUCYNUJĄ nieistniejące symbole.
**Prewencja:** wpisz wprost w system prompt "poszukaj też books/instrukcji", nie
polegaj na tym że agent sam wpadnie na pomysł.

## Tryb porażki #2: nieodkryta mechanika `dismount`

Trzeba móc zejść z pojazdu i dokończyć trasę pieszo — modele tego nie odkrywają same.
Zweryfikowany działający fragment promptu: *"It is possible that other actions that
we don't know about can be used. For example, we know that it is possible to get off
current vehicle."*

## Inne gotchas

- `/api/wehicles` (literówka, jak zwraca ją sam toolsearch) i poprawna pisownia obie
  bywają 404 dla części uczestników — nie ufaj ślepo temu co zwróci toolsearch.
- Do zapytania o mapę wystarczy sama nazwa miasta — nie przesadzaj ze złożonością
  zapytania.
- Budżet jest CIASNY — plan zachłanny (najkrótsza trasa) zawodzi, trzeba faktycznie
  symulować zużycie zasobów krok po kroku.
